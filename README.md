# Anchitya - Modern Portfolio Website

A stunning modern portfolio website built with React, TypeScript, Framer Motion, and Three.js. Inspired by premium portfolio designs with glassmorphism, 3D effects, and smooth animations.

## ✨ Features

### 🎨 Design
- **Glassmorphism Design**: Modern frosted glass UI elements
- **Dark & Light Themes**: Seamless theme switching with persistence
- **Smooth Animations**: Powered by Framer Motion and GSAP
- **Particle Background**: Interactive canvas particles with connections
- **Responsive Design**: Optimized for all devices

### 🚀 Performance
- Built with React 18 & TypeScript
- Vite for ultra-fast development
- Optimized animations with GPU acceleration
- Minimal bundle size

### 📱 Mobile Optimized
- Hamburger menu for mobile navigation
- Touch-friendly interactions
- Responsive typography and layout

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Styling**: CSS3 with CSS Variables
- **Animations**: Framer Motion, GSAP
- **Build Tool**: Vite
- **Icons**: React Icons
- **3D Graphics**: Three.js (ready for implementation)

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/anchitya/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deployment

### GitHub Pages
```bash
npm run build
# Push dist folder to gh-pages branch
```

### Vercel
```bash
npm install -g vercel
vercel
```

### Netlify
```bash
npm run build
# Drag and drop dist folder
```

## 🎯 Sections

- **Hero**: Animated introduction with gradient text and floating backgrounds
- **About**: Professional summary with statistics
- **Skills**: Animated skill bars organized by categories
- **Experience**: Interactive timeline of professional positions
- **Projects**: Showcase of key infrastructure projects
- **Contact**: Multiple ways to get in touch

## 🎨 Customization

### Colors
Edit CSS variables in `src/index.css`:

```css
:root {
  --accent-color: #0066cc;
  --text-primary: #1a202c;
  /* ... */
}
```

### Content
Update content in respective component files:
- `src/components/About.tsx`
- `src/components/Skills.tsx`
- `src/components/Experience.tsx`
- etc.
